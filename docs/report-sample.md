# 數位落差與政治參與：台灣社群媒體使用的世代差異分析

**作者**：王大明　**指導教授**：林教授　**課程**：質性研究方法（113-2）

---

## 摘要

本研究以世代差異為核心，探討台灣民眾的社群媒體使用行為如何影響政治參與意願。研究採取混合方法設計：量化部分以線上問卷蒐集 428 份有效樣本，質性部分進行 12 場深度訪談。研究結果顯示，18–29 歲青年族群的政治資訊獲取高度依賴 Instagram 與 Threads，而 50 歲以上族群仍以 Facebook 與 LINE 為主要管道。迴歸分析顯示，社群媒體使用頻率（$\beta = 0.31$, $p < .001$）與政治參與顯著正相關，但此效果在不同平台間存在明顯差異。本研究的貢獻在於揭示「平台選擇」而非單純「使用頻率」是理解數位政治參與的關鍵變數。

> **關鍵字**：數位落差、社群媒體、政治參與、世代差異、台灣

---

## 一、研究問題與動機

近年來，社群媒體在台灣的政治動員中扮演愈來愈重要的角色——從 2014 年太陽花學運的即時串聯，到近年選舉期間的資訊傳播，數位平台已深刻改變了公民的政治實踐方式[^1]。

然而，既有研究多將「社群媒體使用者」視為同質群體，忽略了**世代間平台偏好的結構性差異**。當青年在 Instagram 上刷著選舉短影音，而他們的父母正在 Facebook 社團裡分享新聞連結，這兩種截然不同的資訊生態，是否也型塑了截然不同的政治參與模式？

本研究試圖回答以下問題：

1. 台灣不同世代在社群媒體平台選擇上有何差異？
2. 平台選擇如何中介社群媒體使用與政治參與之間的關係？
3. 質性訪談能否揭示量化模型無法捕捉的使用者主觀詮釋？

[^1]: 關於太陽花學運與社群媒體的關係，可參考 Ho（2015）的民族誌研究，以及 Chen & Lin（2018）的大數據分析。

## 二、文獻回顧

### 2.1 數位落差的三個層次

Van Dijk（2020）將數位落差概念化為三個相互依存的層次：

| 層次                          | 內涵                   | 衡量指標                     |
| ----------------------------- | ---------------------- | ---------------------------- |
| **接取落差**（Access divide） | 能否取得設備與連網     | 智慧型手機擁有率、網路涵蓋率 |
| **技能落差**（Skills divide） | 能否有效使用數位工具   | 數位素養測驗、操作能力自評   |
| **使用落差**（Usage divide）  | 如何使用及用於何種目的 | 使用時間、平台偏好、內容類型 |

台灣在接取落差方面已大致弭平（網路普及率逾 90%），但**使用落差**——尤其是世代間的平台偏好差異——仍相當顯著（NCC, 2023）[^2]。

### 2.2 社群媒體與政治參與

Boulianne（2015）的統合分析整合了 36 份研究（$N = 52,006$），發現社群媒體使用與政治參與的相關係數平均為 $r = .16$，效果量雖小但穩定存在。然而，此效果高度依賴平台類型與政治情境[^3]。

Norris（2001）的「增強假說」（reinforcement hypothesis）認為，網路使用傾向強化既有的政治行為模式，而非創造新的參與者。對照之下，「動員假說」（mobilization hypothesis）則主張數位工具能觸及原本不參與政治的民眾，尤其是青年族群。

> 「我之前完全不關心政治，但在 Instagram 上刷到幾支關於居住正義的懶人包之後，就開始關注了。那種視覺化、很快就能懂的方式，跟以前看政論節目的感覺完全不一樣。」
>
> ——受訪者 A（24 歲，大學生）

### 2.3 台灣的研究空缺

在台灣脈絡中，現有研究多聚焦於特定事件（如選舉、社會運動）的社群媒體效應，較少以**長期、跨世代的結構性視角**檢視平台使用與政治參與的關係。本研究試圖填補此缺口。

[^2]: NCC（2023）。《112 年通訊市場調查報告》。國家通訊傳播委員會。

[^3]: 此統合分析中，Twitter/X 相關研究的效果量（$r = .22$）顯著高於 Facebook（$r = .12$），作者認為與平台的政治討論文化差異有關。

## 三、研究方法

### 3.1 研究設計

本研究採**順序混合方法**（sequential mixed-methods design）：先以問卷量化確立整體模式，再以深度訪談深化對機制的理解。

```
量化階段（phase 1）
  ↓ 問卷設計 → 線上發放 → 資料清理
  ↓ 敘述統計 → 迴歸分析
  ↓ 識別「異常」案例（高使用、低參與）
            ↓
質性階段（phase 2）
  ↓ 立意抽樣訪談對象 → 半結構訪談
  ↓ 主題分析（thematic analysis）
  ↓ 整合詮釋
```

### 3.2 量化：問卷設計與分析

**樣本**：透過社群媒體廣告與校園公告招募，共回收 461 份問卷，剔除未完成與無效作答後，有效樣本 $N = 428$（回收率 92.8%）。

**主要變數**：

- _社群媒體使用頻率_（SMU）：每日使用時數，1（未使用）至 5（≥4 小時）的 5 點量表
- _政治參與_（PP）：複合指標，涵蓋投票、連署、網路討論、實體抗議 4 個面向，0–8 分
- _平台多樣性_：使用中的平台數量（Facebook、Instagram、Threads、X、YouTube、LINE）
- _控制變數_：年齡、教育程度、政治興趣、媒體信任

**分析策略**：階層迴歸分析（hierarchical regression）。模型一納入人口學控制變數，模型二加入 SMU，模型三加入平台多樣性與交互項。

以 R 進行分析，關鍵程式碼如下：

```r
library(tidyverse)
library(broom)

# 模型三：加入平台多樣性與交互項
model3 <- lm(
  political_participation ~
    age + education + political_interest +   # 控制變數
    smu_frequency +                          # 主效果
    platform_diversity +                     # 平台多樣性
    smu_frequency * platform_diversity,      # 交互項
  data = survey_data
)

tidy(model3, conf.int = TRUE) |>
  filter(p.value < 0.05) |>
  select(term, estimate, std.error, p.value)
```

**卡方檢定**（世代 × 主要使用平台）：

$$\chi^2 = \sum_{i} \frac{(O_i - E_i)^2}{E_i} = 84.3, \quad df = 10, \quad p < .001$$

**政治參與預測方程式**（標準化係數）：

$$\hat{PP} = 0.31 \cdot SMU + 0.24 \cdot PD + 0.18 \cdot SMU \times PD - 0.12 \cdot Age + \epsilon$$

其中 $PD$ 為平台多樣性，$\epsilon \sim \mathcal{N}(0, \sigma^2)$。

### 3.3 質性：深度訪談

從問卷樣本中以立意抽樣選取 12 位受訪者，涵蓋三個年齡組（18–29、30–49、50+）各 4 人，並確保高/低政治參與者各半。訪談時長 60–90 分鐘，全程錄音並逐字謄錄。依照 Braun & Clarke（2006）的反思性主題分析進行編碼。

三個模型的 $R^2$ 依序為 .18、.27、.34，加入平台多樣性後解釋力提升最為顯著（$\Delta R^2 = .07$，$F_{change}(2, 421) = 22.4$，$p < .001$）。

### 4.3 訪談中的主題：資訊生態的「同溫層效應」

質性分析歸納出三個核心主題：

1. **演算法馴化**：受訪者普遍描述社群媒體演算法如何逐漸「學習」其政治偏好，形成封閉的資訊循環
2. **平台文化差異**：Instagram 偏向視覺化、情感動員；Facebook 則傾向長文論述與社群認同強化
3. **跨平台流動**：部分青年受訪者描述在不同平台間扮演「資訊橋接者」的角色

> 「我媽在 Facebook 看到的假新聞，都是我在 Instagram 上看到闢謠文之後，再截圖傳給她的。我變成一個家庭裡的事實查核員，但這很累。」
>
> ——受訪者 F（26 歲，研究生）

以下是訪談資料的初步主題編碼範例（以 Python 示意）：

```python
# 主題分析編碼架構示意
themes = {
    "演算法馴化": [
        "它就一直推給我同樣立場的東西",
        "我知道我活在同溫層，但跳出去很累",
    ],
    "平台文化差異": [
        "Instagram 比較像在激起情緒",
        "Facebook 的人比較愛長篇大論",
    ],
    "跨平台流動": [
        "我會在 Threads 看到，然後截圖貼到家族群組",
    ],
}

for theme, quotes in themes.items():
    print(f"\n【{theme}】共 {len(quotes)} 則例句")
    for q in quotes:
        print(f"  · 「{q}」")
```

## 五、討論與結論

### 5.1 回應研究問題

本研究的三個研究問題均獲得明確回應：

- **世代差異確實存在**，且不僅是使用頻率的差異，更是平台生態系統的根本不同
- **平台多樣性**（而非單一平台的使用強度）是預測政治參與的更佳指標，支持了「資訊雜食性」（information omnivore）假說
- 訪談揭示了量化無法捕捉的**主觀詮釋機制**：受訪者並非被動受演算法操控，而是在平台限制下主動建構政治意義

### 5.2 與既有文獻對話

本研究結果**部分支持**增強假說：高政治興趣者確實透過社群媒體強化既有傾向。但同時也發現**動員效果**，尤其在平台多樣性高的青年群體中——這或許解釋了為何 Boulianne（2015）的統合分析未能得出一致結論。

### 5.3 研究限制

- ~~原計畫納入 TikTok 使用者的比較分析~~，但因倫理審查期程延遲，此部分資料未能及時納入[^4]
- 問卷採自我報告，社會期許偏誤（social desirability bias）難以完全排除
- 橫斷面設計無法推論因果方向：政治參與者是否更傾向使用多樣化平台？
